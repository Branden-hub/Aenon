# Aenon

Aenon is a compact reflective agent that coordinates a collection of modular
capabilities. The project now ships with a browser friendly control panel and a
REST API so that the agent can be driven either from the command line or within
an extension/web environment.

## Features

- **Goal orchestration** – goals are described with a `GoalDescriptor` and the
  agent selects the capabilities that can contribute.
- **Capability suite** – includes autonomous learning, self improvement, cross
  domain synthesis, dynamic capability planning and a human feedback loop.
- **Persistent memory** – a lightweight JSON based store keeps track of goals,
  reports and actuator results.
- **Web interface** – FastAPI serves an interactive single page app that runs
  entirely in the browser.

## Getting started

Create a Python virtual environment and install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Command line usage

Run the agent with a sample smart home optimisation goal:

```bash
python main.py
```

The script prints a structured report generated by the registered capabilities.

### Web application

Launch the FastAPI server and open `http://localhost:8000` in the browser:

```bash
uvicorn webapp.server:app --reload
```

The control panel lets you describe new goals, inspect capability output, send
feedback to the human collaboration module and review recent memory entries.

## Project structure

```
core/            # Orchestration logic and bootstrap helpers
capabilities/    # Individual capability modules
interfaces/      # Actuator simulations
memory/          # Persistent JSON memory store
webapp/          # FastAPI server and static single page app
```

## Development

- Run the command line entry point (`python main.py`) to verify the backend.
- Start the web server (`uvicorn webapp.server:app --reload`) for the browser UI.
- Memory entries are stored under `./memory_db/aenon_memory.json` and can be
  cleared by deleting the file or calling `InfiniteMemory.clear()`.
