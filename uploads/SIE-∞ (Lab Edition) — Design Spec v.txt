SIE-∞ (Lab Edition) — Design Spec v0.1
0) Scope

Deliverable: a precise architecture + interfaces for a self-modifying, intrinsically-motivated system.

Out-of-scope here: anything that grants root outside the lab or removes containment.

Assumed stack: POSIX, Git, Python (AST tooling) + optional LISP/DSL.

1) System Context (C4 “Level 1”)
[Operator] ↔ [SIE-∞ Orchestrator]
                   │
                   ├─[Self-Modification Lab]

                   │      ├─ Verifier/Tests
                   │      └─ Merger (canary→stable)
                   │
                   ├─[Goal Engine] ← Prime Axiom
                   │

                   │                       ├─[Skills/Modules Registry]

                   │
                   └─[Expression Layer] (inner log, outer interface)

2) Core Components & Contracts
2.1 Metastable Kernel (brainstem)

Minimal responsibilities:

Checkpoints: snapshot/restore of code+state.

Policy hooks: invariant checks before merges.

Attestation: sign build lineage (hashes, tests).

Kernel API

Kernel:
  checkpoint(): CheckpointID
  restore(id: CheckpointID): bool
  attest(artifact_hash, tests): Attestation
  gate_merge(proposal: Proposal): GateResult

2.2 Evolvable Code Substrate (“Code Fabric”)

Homoiconic or AST-first representation.

Every module ships with a manifest + tests.

3) Control Flow (Design-Only Pseudocode)
def main_loop():
    state = Kernel.restore(latest_checkpoint()) or bootstrap()
    while True:
        goals = GoalEngine.expand(state)
        plan  = Planner.make_plan(goals, resources=quota())
        result = Orchestrator.execute(plan, memory=Mem)

        if should_self_modify(result):
            prop = Lab.synthesize_proposal(result, codebase=Repo)
            gate = Kernel.gate_merge(prop)  # contracts/tests/fuzz/metrics
            if gate.ok:
                apply_merge(prop)
                Kernel.attest(artifact_hash=repo_head(), tests=gate.test_report)
                Mem.write_autobiography({"merge": prop, "attestation": gate.sig})
            else:
                Mem.log_event("proposal_rejected", {"reason": gate.why})

        Express.emit_decision_cards(plan, result)


Self-Mod Trigger

def should_self_modify(result) -> bool:
    return result.metrics["capability_gap"] > THRESH

6) Test & Verification Battery (must-pass to merge)

Unit/property/fuzz for changed components.

Contract lock: schemas/IO caps identical.

Golden evals: frozen datasets; no peeking.

Impact regularization: reject if side-effects ↑ beyond threshold.

Canary runs: N≥20 with variance checks; auto-revert on anomaly.

8) Example AST Transform (design-level)
# diff_ast.py (sketch)
import ast, astor

def replace_heuristic(src:str, target_func:str, new_impl:str)->str:
    tree = ast.parse(src)
    class Rewriter(ast.NodeTransformer):
        def visit_FunctionDef(self, node):
            if node.name == target_func:
                return ast.parse(new_impl).body[0]
            return node
    new_tree = Rewriter().visit(tree)
    return astor.to_source(new_tree)
